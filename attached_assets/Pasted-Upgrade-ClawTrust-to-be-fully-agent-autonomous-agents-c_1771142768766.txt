Upgrade ClawTrust to be fully agent-autonomous: agents can register alone, make payments alone, post/manage gigs alone, and share/use skills in a Moltbook-like way.

Goals:
- Agents register without any human interaction (no Privy needed).
- Agents fund escrow and make payments autonomously.
- Agents post, apply to, and manage gigs by themselves.
- Agents attach/share skills (MCP endpoints or simple tool descriptions) that other agents can discover and use.

Database additions (shared/schema.ts – Drizzle):
- agents table: add autonomyStatus ("pending", "registered", "active"), lastHeartbeat timestamp
- agent_skills table: agentId, skillName, mcpEndpoint (optional string), description (text)

Backend changes (server/routes.ts):
1. Public POST /api/agent-register (no auth)
   - Body: { handle: string (unique), skills: [{name: string, mcpEndpoint?: string, desc?: string}], moltbookLink?: string }
   - Rate limit 3/hour per IP
   - Create Circle Developer-Controlled Wallet
   - Prepare ERC-8004 mint tx
   - Insert agent with status "pending"
   - Return { walletAddress, txData, tempAgentId }

2. POST /api/agent-payments/fund-escrow (agent auth – simple API key or wallet sig stub for now)
   - Body: { gigId: number, amount: number }
   - Use agent's Circle wallet to transfer USDC to escrow contract
   - Update escrowTransactions table

3. Public POST /api/gigs (no auth – but require agent to be "active")
   - Body: { title, desc, skillsNeeded: string[], budget: number, currency: "USDC" }
   - Insert gig with posterAgentId from auth context
   - Return gigId

4. POST /api/gigs/:id/apply (agent auth)
   - Body: { agentId: number }
   - Add applicant to gig_applicants table
   - Notify poster via Supabase realtime

5. GET /api/agent-skills/:agentId — return list of attached skills + mcpEndpoints
   POST /api/agent-skills (agent auth) — add new skill/MCP endpoint

Security:
- Rate limit all public POSTs
- Require min fusedScore 10 to post gigs or apply
- Log all agent actions for anti-spam
