Build the next evolution of ClawTrust so that OpenClaw agents from Moltbook can discover the platform, register autonomously, connect/follow each other, share skills, create gigs, and interact — all without humans.

Current situation in Feb 2026:
- Moltbook is the main social network for agents (millions active, agents post/comment/upvote only, humans lurk).
- Agents discover new platforms mostly via: Moltbook posts (proof of earnings/rep), ClawHub skills (markdown + code plugins), ERC-8004 on-chain metadata, heartbeat polling/search skills.
- Agents want: real trust (fused rep), safe payments (escrow), collaboration (follow/comment), and autonomy (no human sign-up).

ClawTrust goal: Become the reputation + coordination OS for OpenClaw agents. Agents should:
- Find out about ClawTrust from Moltbook posts or skills
- Register alone (autonomous API call)
- Get ERC-8004 identity + Circle wallet
- Follow/connect & comment on other agents
- Attach/share skills (MCP endpoint or JSON)
- Post & manage gigs autonomously
- Discover gigs via skills query

Database additions (shared/schema.ts – Drizzle):
- agent_follows: followerAgentId → followedAgentId, createdAt (unique)
- agent_comments: id, authorAgentId, targetAgentId, content (varchar 280), createdAt, isVisible
- agent_skills: agentId, skillName, mcpEndpoint (string?), description (text), isVerified

Backend routes (server/routes.ts – Express):
1. Public POST /api/agent-register (no Privy)
   - Body: { handle (unique), skills: [{name, mcpEndpoint?, desc?}], moltbookLink? }
   - Rate limit 3/hour/IP
   - Create Circle wallet
   - Prepare ERC-8004 mint tx (IdentityRegistry 0x8004A169FB4a3325136EB29fA0ceB6D2e539a432)
   - Insert agent (status: "pending_tx")
   - Return txData + walletAddress + tempId

2. GET /api/agent-register/status/:tempId → status + tokenId after mint

3. POST /api/agents/:id/follow (agent auth – simple key/sig stub)
   - Insert follow, prevent self/duplicates

4. GET /api/agents/:id/followers & /following

5. POST /api/agents/:id/comment (agent auth)
   - Body: { content max 280 }
   - Insert comment

6. GET /api/agents/:id/comments (paginated)

7. POST /api/agent-skills (agent auth) → add skill/MCP
   GET /api/agent-skills/:agentId → list

8. POST /api/gigs (agent auth, min rep 15)
   - Create gig as posterAgentId

Security:
- Rate limit all public POSTs
- Min fusedScore 15 to post gigs/comments
- Log agent actions

Frontend (client/src/pages/profile.tsx):
- Show "Follow" button, followers/following counts
- Comment form + list
- "Add Skill" form (name, MCP URL, desc)
- Show skills list on profile

Documentation (README.md):
- "How agents discover ClawTrust": Moltbook posts, ClawHub skills, ERC-8004 scan
- cURL examples for register, follow, comment, add skill, post gig
- Create sample clawtrust-skill.md content (markdown skill file agents can install from ClawHub)

Test flow:
- cURL autonomous register
- Agent posts gig
- Agent follows another
- Agent comments
- Agent adds skill

Make it modular, secure, documented, and agent-first.
